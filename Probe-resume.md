# Использование входа PROBE для Resume

Прошивка позволяет переназначить вход `PROBE/IN4` (`PB15`) на аппаратное
продолжение программы после команды `M0`.

## Настройка

```text
$7=0
```

Штатный режим по умолчанию: вход работает как щуп, команды `G38.2`–`G38.5`
разрешены.

```text
$7=1
```

Вход используется для Resume. Активный сигнал действует как realtime-команда
`~`, но только когда программа остановлена командой `M0`. Команды
`G38.2`–`G38.5` в этом режиме возвращают ошибку `error:20`.

Текущее значение можно увидеть в общем отчёте настроек:

```text
$$
```

Полярность входа по-прежнему задаётся стандартной настройкой `$6`:

```text
$6=0
$6=1
```

## Пример программы

```gcode
G1 X100 F500
M0
G1 Y100 F500
```

После выполнения `M0` контроллер завершает буферизованные перемещения и
переходит в `HOLD`. Для продолжения вход необходимо сначала перевести в
неактивное состояние, а затем активировать не менее чем на 30 мс.

Требование предварительного отпускания не позволяет постоянно активному или
замкнутому входу автоматически пропустить новую паузу.

## Ограничения безопасности

Сигнал обрабатывается только при одновременном выполнении условий:

- включено `$7=1`;
- состояние контроллера — `HOLD`;
- торможение завершено и станок полностью остановлен;
- причиной программной паузы является `M0`.

Вход не запускает программу из `IDLE`, не снимает `ALARM`, не отменяет
`Safety Door` и не возобновляет обычный Feed Hold, вызванный командой `!`.

`PB15` настроен без внутренней подтяжки (`GPIO_NOPULL`). Если на плате нет
внешней подтяжки, её необходимо установить. На вход допускается только
логический уровень, совместимый с STM32 (`0–3,3 В`). Для внешнего датчика
предпочтительны сухой контакт, открытый коллектор или гальваническая развязка.

## Обновление прошивки

Настройка хранится в EEPROM. При первом запуске новая прошивка автоматически
переносит настройки формата v11 в v12 и устанавливает `$7=0`, сохраняя
остальные параметры станка.
